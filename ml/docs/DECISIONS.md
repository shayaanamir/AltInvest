| D21 | Model evaluation uses expanding-window walk-forward over rows [0, b2-30) (train+validation together). Thresholds (D19) and baseline parameters are refit per fold from that fold's train rows only; evaluation labels use that fold's thresholds. | D34 | Backtest protocol (Phase 5; EVALUATION.md rules 4-5). Windows: the walk-forward fold origins (non-overlapping, 30 rows apart, pre-test only); the signal at origin t comes from that fold's fit. Positions: long-only spot; BUY = long for the 30-day window; HOLD, SELL and UNCERTAIN = cash (0 return). Cost: 0.1% per side, charged on each change of position (config.BACKTEST_FEE_PER_SIDE = 0.001). Strategies: (1) served policy (D33, all UNCERTAIN); (2) reference row, evidence only and never served: 4c top config through generate_signal with serving forced on, argmax rule UP->BUY, DOWN->SELL, FLAT->HOLD, no thresholds, no tuning. Baselines: buy-and-hold, always-HOLD, random (P(BUY) = 0.5 per window, 1000 runs, seed 0; report percentiles of cumulative return and Sharpe, and the reference row's percentile rank). CIs: bootstrap with block 1 (windows do not overlap); paired CI of mean window return, reference minus buy-and-hold and minus always-HOLD. Reported, not used for approval | User decision, 2026-10-20 |

| D36 | risk_score mapping (refines D9, D24, D27; PLANNER 7.4 per-asset proposal replaced). risk_score = 100 x (1 - p), where p is the percentile rank (ties count half) of today's vol_30d among the vol_30d values of ALL served assets (config.ASSETS) on all dates <= today.
